The World Today — 24 November 2026: a one-page newspaper poster summing up the day's world news in a single image. Six stories: Nvidia's chief executive returns, the COP31 climate summit collapses, a Russian warship is claimed sunk off Libya, Iran feels the squeeze, the EU's 22nd sanctions package, and Mexico's capture of "El Chapo Isidro".

## Run it

```sh
python3 main.py
```

It writes the poster to `/output/entry.png` (1024x1024, pure Python standard library, deterministic — same bytes every run).
